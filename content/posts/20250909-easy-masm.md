Hello, COMP-2660 students! If you have a MacBook or is having issues with MASM on your Windows laptop, then this guide is for you. Install Easy-MASM on GitHub codespace, a cloud-powered remote development environment, to run MASM assembly codes.

# Steps to Installing Easy-MASM

## 1. Create a GitHub Account

To start using GitHub codespace, first navigate to https://github.com/ to create a GitHub account. As of now, all GitHub personal account allows for 120 monthly core-hours (\*) of GitHub codespace usage without incurring additional costs.

> (\*) The actual usage hour will vary depending on the type of codespace you use. Typically, the minimum number of cores in a GitHub codespace is 2, meaning that you will get 60 hours of actual usage, as opposed to 120.
> You can apply for the [GitHub student developer pack](https://education.github.com/pack), which comes with GitHub Pro, to extend your monthly core-hours to 180.

## 2. Create a GitHub Repository

After creating a GitHub account, log in and create a new repository via the `"Create new..."` button (plus sign) on the top right corner of the GitHub page. Use this repository as a container for the code you will write throughout the semester.

> [!WARNING]
> Make sure that your repository's visibility is set to private. Otherwise, everything you commit to the repository will be out for the world to see! Also make sure to enable the readme file, since codespaces cannot be created on an empty repository.

> [!TIP]
> While on this topic, take a look at how [committing works in Git](https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/about-commits) as you're working on your code in the codespace.

## 3. Create a GitHub Codespace

At the dashboard of your repository, there should be a green `"Code"` button. Click on the button and select the option `"Create codespace on main"` (you may have to click on the "Codespace" tab to see this).

This will bring up a new tab with an URL ending with 'github.dev', which is the URL that you will access the codespace's development environment from during the time it is active. By default, a 2-core codespace of Linux environment is created.

## 4. Install Wine

For Linux environments, `wine` is a prerequisite for Easy-MASM. Open a terminal in your codespace and input the following commands one at a time:

```bash
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install wine32
```

## 5. Install Easy-MASM

In the same terminal, type in the following commands one at a time:

```bash
git clone https://github.com/jere-mie/easy-masm
cd easy-masm
chmod +x run.sh
```

To test if your installation is successful, run the following command while remaining in the easy-masm folder on the terminal:

```bash
./run.sh source
```

## 6. Stop the Codespace

A good practice to follow is to stop your codespace whenever you're not using them. GitHub codespaces, by default, idles for 30 minutes before timing out and stopping the codespace. If you simply closed the browser tab, the codespace will not be stopped, and usage will still be counted and billed.

To stop the codespace, click on the `"Codespaces: [your codespace name]"` tab on the bottom left corner of your codespace brower tab. On the list of options provided, select "Stop current codespace".

You can always go back to your codespace via https://github.com/codespaces and re-start it whenever you need to use MASM again.
